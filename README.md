# As Shadiq Nur

Mahasiswa Teknik Informatika di UIN Alauddin Makassar. Saya membuat aplikasi untuk memudahkan hal-hal yang saya alami sendiri. Kalau sebuah pekerjaan terasa ribet atau makan waktu, biasanya saya coba buatkan alatnya. Sehari-hari saya memakai Python dan TypeScript.

Situs pribadi: [As Shadiq Nur](https://higieka.web.id/)

## Proyek

- **LKH KKN untuk iOS**: Versi iPhone dari aplikasi presensi KKN yang sebelumnya hanya ada di Android. Pencocokan wajah dengan foto pendaftaran berjalan di perangkat. React Native, Expo, TypeScript, TensorFlow Lite.
- **[Dashboard admin LKH KKN](https://higieka.web.id/kkn/)**: Rancangan dashboard untuk pengelola KKN. Tabel pendaftar dibaca langsung dari Google Sheet, lengkap dengan formulir pendaftaran dan templat impor Excel.
- **Lokasi**: Aplikasi Windows untuk menguji fitur lokasi di iPhone lewat joystick, peta, atau koordinat. Python, Tkinter, pymobiledevice3.
- **Pemeriksa naskah PKTI**: Memeriksa format, bahasa, dan kelengkapan proposal atau skripsi (.docx) berdasarkan Pedoman Karya Tulis Ilmiah UIN Alauddin Makassar. Python, OOXML.
- **[Pukat](https://higieka.web.id/pukat/)**: Pengumpul korpus media sosial untuk penelitian. Pengumpulan data dijalankan lewat Apify, lalu hasilnya diolah dan diekspor langsung di peramban.
- **[My Phones Store](https://github.com/GieKA21/final_project)**: Aplikasi toko ponsel dengan halaman produk, login, dan panel admin. Flutter, SQLite.
- **[Booking wisata](https://github.com/GieKA21/bdnr_final)**: Aplikasi web pemesanan tempat wisata dengan akun pengguna dan halaman admin. Flask, MongoDB.

Detail dan demo proyek ada di [higieka.web.id](https://higieka.web.id/).

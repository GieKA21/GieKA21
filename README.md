# As Shadiq Nur

Mahasiswa Teknik Informatika di UIN Alauddin Makassar. Saya membuat aplikasi untuk kebutuhan kampus, dari presensi KKN di iPhone sampai alat pengujian lokasi di Windows. Sehari-hari saya memakai Python dan TypeScript.

Situs pribadi: [As Shadiq Nur](https://higieka.web.id/)

## Proyek

- **LKH KKN untuk iOS**: Versi iPhone dari aplikasi presensi KKN yang sebelumnya hanya ada di Android. Pencocokan wajah dengan foto pendaftaran berjalan di perangkat. React Native, Expo, TypeScript, TensorFlow Lite.
- **Lokasi**: Aplikasi Windows untuk menguji fitur lokasi di iPhone lewat joystick, peta, atau koordinat. Python, Tkinter, pymobiledevice3.
- **Pemeriksa naskah PKTI**: Memeriksa format, bahasa, dan kelengkapan proposal atau skripsi (.docx) berdasarkan Pedoman Karya Tulis Ilmiah UIN Alauddin Makassar. Python, OOXML.

Detail dan demo setiap proyek ada di [higieka.web.id](https://higieka.web.id/).
